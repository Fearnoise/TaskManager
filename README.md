# TaskManager
Корпоративная система управления задачами с JWT-аутентификацией, Master-Slave репликацией БД и аналитикой в реальном времени. Двухфреймворковая архитектура: Core (FastAPI) + Supporting (Express.js). Полный CRUD, фильтрация, пагинация, дашборд с Highcharts. Чистые SQL-запросы, резервные ответы, тесты.
